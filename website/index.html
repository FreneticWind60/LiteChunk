Open Source

站在 Chunker 的肩上

转换引擎来自 Chunker —— 一个由Hive Games 开源、以 MIT 协议发布的 Minecraft 存档转换器。这份移植保留了它的核心逻辑，裁掉了手机端用不上的部分，并为 Android 运行时补了几处必要的兼容补丁。

这个项目的起点是同类应用 Chunkoid：它先证明了在手机上做存档转换是行得通的，也促成了 LiteChunk 的出现。同时在技术上，此项目参考了具有类似功能的应用TheoCraft的实现方式。不同的是，LiteChunk 不追求功能齐全，而是把包体、内存和界面都压到最小——谢谢它蹚出的这条路，也推荐给有同样需要的朋友。

引擎以独立的 dex 随安装包一起分发，通过 DexClassLoader 加载；这部分同样以 MIT 协议开源。改了哪些地方、为什么改，都写在仓库的 README 里。
