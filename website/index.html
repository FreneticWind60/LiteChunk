why litechunk

把「够用」做到刚好

同类工具注重功能的丰富性，LiteChunk 反过来：能删的都删了，剩下的只有你的世界。

轻

一个安装包装下完整的转换引擎，不用再下载 JRE 运行时。

离线

转换全程在本机完成，存档一个字节都不上传。整个应用只有「检查更新」一处网络请求。

可控

进度卡显示阶段、百分比与已用时，随时可取消。转换期间前台服务加唤醒锁，挂小窗也能跑完。

干净

没有开屏、没有弹窗。输出目录就一个，按格式分好，不用在文件堆里找。

怎么用

四步，没有隐藏菜单

选存档

从文件管理器挑 .zip 或 .mcworld，也可以把存档直接分享进 LiteChunk。

选格式与版本

目标选 Java 或基岩，再从版本列表里挑目标版本，默认按源存档自动带出。

开始转换

进度、阶段、用时都在卡片上，中途可以直接取消，不会留下半成品。

保存或导入

导出到任意目录、分享给别的应用，装过基岩版还能一键丢进游戏目录。
